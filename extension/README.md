# 🧩 Recipe Distiller — розширення для браузера (Manifest V3, unpacked)

Кнопка на панелі інструментів: перебуваючи на сторінці рецепта, одним кліком
відкриває ваш локальний Recipe Distiller із цією URL у полі — дистиляція
починається одразу. Жодних дозволів на вміст сторінок не потрібно
(лише `activeTab` + `storage`).

## Встановлення (Chrome / Edge / Brave, ~1 хвилина)

1. Запустіть сервер Recipe Distiller (`start.bat` на Windows — див. `INSTALL.md`).
2. Відкрийте `chrome://extensions` (Edge: `edge://extensions`).
3. Увімкніть **Режим розробника** (Developer mode) — перемикач у куті.
4. Натисніть **Завантажити розпаковане** (Load unpacked) і виберіть цю папку
   `extension/`.
5. Закріпіть іконку 🍲 на панелі (пазур → «Закріпити»).

## Використання

- Відкрийте будь-яку сторінку з рецептом і клацніть іконку — distiller
  відкриється в новій вкладці з цією URL і одразу почне витягати рецепт.
- Адреса сервера за замовчуванням — `http://localhost:8000`. Змінити: правий
  клік по іконці розширення → **Параметри** (Options) → вкажіть свою адресу
  (наприклад, `http://192.168.1.10:8000`, якщо сервер на іншій машині).

## Файли

- `manifest.json` — Manifest V3, дозволи: `activeTab`, `storage`.
- `background.js` — service worker: обробляє клік по кнопці.
- `options.html` / `options.js` — сторінка налаштувань адреси сервера.
